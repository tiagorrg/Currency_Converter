# Currency Converter

Currency Converter — это приложение на Flutter, которое позволяет пользователям конвертировать суммы между различными валютами с использованием актуальных курсов обмена.

## Установка
1. **Установите Flutter**:
   - Следуйте официальной документации Flutter для установки на вашу операционную систему: [Flutter Installation Guide](https://flutter.dev/docs/get-started/install).

2. **Клонируйте репозиторий**:
      git clone https://github.com/tiagorrg/Currency_Converter.git
   

3. **Перейдите в директорию проекта**:
      cd Currency_Converter
   

4. **Установите зависимости**:
      flutter pub get
   

## Запуск
Запустите приложение с помощью следующей команды:
flutter run

## Использование
1. **Ввод суммы**:
   - Введите сумму, которую вы хотите конвертировать, в поле "Amount".

2. **Выбор валют**:
   - Выберите исходную валюту из выпадающего списка "From Currency".
   - Выберите целевую валюту из выпадающего списка "To Currency".

3. **Конвертация**:
   - Нажмите кнопку "Convert", чтобы выполнить конвертацию.
   - Результат конвертации отобразится в поле "Converted Amount".

## Пример использования
1. Введите сумму `100` в поле "Amount".
2. Выберите `USD` в качестве исходной валюты.
3. Выберите `RUB` в качестве целевой валюты.
4. Нажмите кнопку "Convert".
5. Результат конвертации будет отображен в поле "Converted Amount".
